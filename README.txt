MEDIA CURATOR
=============
Lightweight photo & video curation tool (GOOD / MAYBE / BAD).

HOW TO RUN
1. Extract this ZIP.
2. Open the MediaCurator folder.
3. Double-click MediaCurator.exe.

Version 0.1.0 - Phase 1 (application shell only). Nothing is functional yet
except switching between the PHOTO and VIDEO tabs. This build exists to prove
that the cloud build pipeline works.
